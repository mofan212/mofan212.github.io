本站的一些事

本站于 2020 年 5 月 28 日开始运行，最初使用 Hexo + hexo-theme-butterfly，现已迁移至 Astro，并基于 AstroPaper 持续维护。

1. 背景

2020 年的寒假，是大三的寒假。

在学校划水摸鱼两年的我，突然意识到不能再迷茫下去，决定在寒假中恶补落下的课程。经过大半个寒假的学习，在寒假结束的最后几天，决定实操一个小系统用来练手，最终选定了个人博客系统，打算使用 Spring Boot + Thymeleaf + Semantic UI 来实现。然而，还是没有抓住寒假的尾巴，由于疫情的原因，在这个「寒假」迎来了网课。

就这样，当初信心满满的博客就这样搁置了，直到…

2. 博客的搭建与演变

2.1 旧站：Hexo + Butterfly

转眼间，大半个学期就这样过了，平时课程学习之余也进行着专业课的探索，争取给实习做好准备，于是决定在 2020 年 5 月 28 日开始搭建自己的第一个博客。

Hexo + hexo-theme-butterfly + 一些魔改

在技术的选择上，没有选择拾起以前的项目，而是使用 Hexo 搭建一个静态博客。

正如 Hexo 的官网所说，Hexo 是一个简单、高效且强大的博客框架，而我在使用时也深有体会，只需要一些环境，你就可以在一集电视剧的时间内搭建出一个简易的博客。这样的一个博客虽然也够使用，但和美观就沾不上边了，因此我又选择 hexo-theme-butterfly 作为 Hexo 的主题。

看中 hexo-theme-butterfly 的原因很简单，它的 UI 风格和我先前搁置的博客很像。如果你也想搭建一个博客，但不喜欢这个主题，可以到 GitHub 上使用 hexo theme 作为关键词进行搜索，也可以找到许多好看的主题。

博客的美观问题解决了，但是功能依旧有点少，于是就使用了一些大佬的魔改，外加上自己的理解，逐渐形成了旧站当时的界面。

3. 关于「默烦」

COVID-19 还未出现在人们的视野里时，那时候的大学生还在教室上课，临近期末也可以在寝室通宵复习。

期末考试的前一天晚上，通宵预习《马克思主义基本原理概论》的我看到了「默顿」这个人名，在中二之魂的加持下，脑海中蹦出「默烦」两个字，其原始含义为：

  • 并不是沉默，只是很烦

之后又把常用社交软件上的昵称都改成了「默烦」，至于预习嘛…

幸好马原还是稳稳地压线过了 😌

如今「默烦」更加趋向于「莫烦」，即：不要烦，意在暗示自己保持积极向上。

至于所用的 ID 为 mofan212，是因为大多数网站上名为 mofan 的 ID 都被注册了，而我的生日是农历二月十二，因此在末尾加上一个 212，尽管含有数字的 ID 不够专业、高级，但是又有什么办法呢？212 似乎还有另外的意思，一个表示二进制，一个表示二次元？ 🤔
