1. Typora 的使用

1.1 下载

Typora 官网：Typora

进入官网找到下载位置，进行下载安装即可~

1.2 图片处理

在 Typora 中，或者说 Markdown 语法中，图片都是引用的，并不是直接嵌入文章的。其实很好理解，就和 HTML 中的 <img> 一样，设置一个路径，然后图片就可以显示了，如果路径错误或者图片不存在，那图片就无法显示。

而对于 Typora 来说，在文章里引用图片是十分简单的，可以直接将图片拖拽进文章，Typora 会自己定位图片的绝对路径并引用图片。各种截图可以直接在 Typora 中复制，截取的图片可以直接在 Typora 中引用，它们会保存在用户路径下。

为了方便图片的整理可以将文章分成不同的类，每类文章中有单独存放的图片文件夹，以便快速寻找、图片或修改图片。比如：

针对这一点，需要对 Typora 进行以下设置，这 Typora 顶部菜单栏找到 格式 一项：

  • 格式 --- 图像 --- 设置图片根目录…
  • 格式 --- 图像 --- 当插入本地图片时 --- 复制图片到文件夹…

设置图片根目录

Q：为什么要设置图片根目录？

A：设置了图片根目录会让图片的引用路径从绝对路径变成相对路径。

Q：那这有啥用？

A：每类文章都设置了不同的图片存放文件夹，并且文章和图片存放文件夹处于同一目录下，如果需要转移文章目录，直接拖动文件到目标位置即可，无需修改图片引用路径，这就是设置了根目录的魅力！😎

A：除此之外可以更方便地备份，比如存入 U 盘，然后在不同的 PC 上查看，还可以备份到云上。绝对路径相比于相对路径，直接在 U 盘中打开文章也可以直接看到图片，备份到云上后下载下来也可以直接看到图片。这就是！设置了！根目录的！魅力！🎉

复制图片到文件夹

Q：为什么要设置「复制图片到文件夹」？

A：截图后自接复制到 Typora 中时，Typora 会将这些图片保存到用户目录（C 盘下的一个目录）下，不方便管理。在设置了「复制图片到文件夹」后，这些图片就会保存在设置的文件夹中，实现图片分类整理。

A：如果将本次设置和上一步设置搭配使用，就可以将截取的图片存放到指定的文件中，并且图片的引用还是相对路径，文章、图片的备份就会更加简单，直接将最外层文件夹拖拽进 U 盘或上传至云即可。那是相当的奈斯啊！👍

Q：使用 picGo 不好吗？直接将图片传到图床，干嘛还将图片留到本地？

A：这就是个人习惯的问题了，首先图床这个东西并不是绝对信任的，养成备份的习惯，更能有备无患，在本地保留一份（或多备份几份）是必要的。

2. Markdown 语法

本语法适用于在 Typora 编译器，不同的编译器对 Markdown 语法的编译可能不同，但大同小异。

2.1 标题

  1. 可以使用 # 表示 1-6 级标题，一级标题对应一个 # 号，二级标题对应 ## 号，依次类推。

2.2 段落格式

2.2.1 段落

  1. 段落的换行是使用两个以上空格加上回车
  2. 或者输入完内容后直接回车即可

2.2.2 字体

123456*斜体文本*
_斜体文本_
**粗体文本**
__粗体文本__
***粗斜体文本***
___粗斜体文本___

2.2.3 分割线

可以在一行中用三个以上的星号、减号、底线来建立一个分隔线，行内不能有其他东西，也可以在星号或是减号中间插入空格。

123456789***

* * *

*****

- - -

----------

2.2.4 删除线

如果段落上的文字要添加删除线，只需要在文字的两端加上两个波浪线 ~~ 即可：

123bilibili.COM
GOOGLE.COM
~~BAIDU.COM~~

比如：删除线

2.2.5 下划线

下划线可以通过 HTML 的 <u> 标签来实现：

1<u>带下划线文本</u>

比如： 带下划线文本

2.2.6 脚注

脚注是对文本的补充说明：

1[^要注明的文本]

比如：我后面有一个脚注1

2.3 列表

Markdown 支持有序列表和无序列表。

无序列表使用星号 *、加号 + 或是减号 - 作为列表标记：

123456789101112* 第一项
* 第二项
* 第三项

+ 第一项
+ 第二项
+ 第三项


- 第一项
- 第二项
- 第三项
  • 第一项
  • 第二项
  • 第三项

2.3.1 列表嵌套

列表嵌套只需在子列表中的选项添加四个空格即可：

1234561. 第一项：
    - 第一项嵌套的第一个元素
    - 第一项嵌套的第二个元素
2. 第二项：
    - 第二项嵌套的第一个元素
    - 第二项嵌套的第二个元素
  1. 第一项：
    • 第一项嵌套的第一个元素
    • 第一项嵌套的第二个元素

2.4 区块

Markdown 区块引用是在段落开头使用 > 符号，然后后面紧跟一个 空格 符号：

1> 区块引用

区块应用

区块是可以嵌套的，一个 > 符号是最外层，两个 > 符号是第一层嵌套，以此类推：

123> 最外层
> > 第一层嵌套
> > > 第二层嵌套

最外层

第一层嵌套

第二层嵌套

2.4.1 区块中使用列表

区块中使用列表实例如下：

123456> 区块中使用列表
> 1. 第一项
> 2. 第二项
> + 第一项
> + 第二项
> + 第三项

区块中使用列表

  1. 第一项

  2. 第二项

  • 第一项
  • 第二项

2.4.2 列表中使用区块

如果要在列表项目内放进区块，需要在 > 前添加四个空格的缩进。

区块中使用列表实例如下：

1234* 第一项
    > 我是区块
    > 我是区块
* 第二项

  • 第一项

    我是区块

    我是区块

  • 第二项

2.5 代码

如果是段落上的一个函数或片段的代码可以用反引号 ` 把它包起来，例如：

1`System.out.print()` 函数

System.out.print() 函数

2.5.1 代码区块

代码区块使用 4 个空格 或者一个 制表符（Tab 键）。你也可以用三个反引号（ ``` ）包裹一段代码，并指定一种语言（也可以不指定）：

实例如下：

12345```javascript
$(document).ready(function () {
alert('hello world!');
});
```

2.6 链接

链接使用方法如下：

12345[链接名称](链接地址)

或者

<链接地址>

比如：这是一个 B站链接

<www.bilibili.com>

2.6.1 高级链接

1234567链接也可以用变量来代替，文档末尾附带变量地址：
这个链接用 1 作为网址变量 [Google][1]
这个链接用 baidu 作为网址变量 [Baidu][baidu]
然后在文档的结尾为变量赋值（网址）

  [1]: https://www.google.com/
  [baidu]: https://www.baidu.com/

比如：这个链接用 1 作为网址变量百度

2.7 图片

Markdown 图片语法格式如下：

123![alt 属性文本](图片地址)

![alt 属性文本](图片地址 "可选标题")
  • 开头一个感叹号 !
  • 接着一个方括号，里面放上图片的替代文字
  • 接着一个普通括号，里面放上图片的网址，最后还可以用引号包住并加上选择性的 title 属性的文字

Markdown 还没有办法指定图片的高度与宽度，如果需要，你可以使用普通的 <img> 标签。比如：<img src="xxxxxxxxx" width="50%">

2.8 表格

Markdown 制作表格使用 | 来分隔不同的单元格，使用 - 来分隔表头和其他行。

语法格式如下：

1234|  表头   | 表头  |
|  ----  | ----  |
| 单元格  | 单元格 |
| 单元格  | 单元格 |
表头表头
单元格单元格
单元格单元格

可以使用表格上方的对齐方式调整表格的对齐方式，也可以在书写时调整表格的对齐方式。

  • -: 表示设置内容和标题栏居右对齐
  • :- 表示设置内容和标题栏居左对齐
  • :-: 表示设置内容和标题栏居中对齐
1234| 左对齐 | 右对齐 | 居中对齐 |
| :-----| ----: | :----: |
| 单元格 | 单元格 | 单元格 |
| 单元格 | 单元格 | 单元格 |

2.9 首行缩进

可以在段首加入 &ensp 来表示一个空格，或者使用 &emsp 表示两个空格。

为什么要使用这种方式，因为在不同的 Markdown 编译器中，直接输入空格或者制表符可能无法显示。虽然在 Typora 上可以正常显示，但将文件传到个人博客之类的支持 Markdown 语法的网站可能会失效。

2.11 高级

2.11.1 支持的 HTML 元素

不在 Markdown 涵盖范围之内的标签，都可以直接在文档里面用 HTML 撰写。

目前支持的 HTML 元素有：kbd、b、i、em、sup、br 等，如：

1使用 <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>Del</kbd> 重启电脑

2.11.2 转义

Markdown 使用了很多特殊符号来表示特定的意义，如果需要显示特定的符号则需要使用转义字符，Markdown 使用反斜杠转义特殊字符：

12**文本加粗** 
\*\* 正常显示星号 \*\*

结果：加粗 、**显示星号**

Markdown 支持以下这些符号前面加上反斜杠来帮助插入普通的符号：

123456789101112\   反斜线
`   反引号
*   星号
_   下划线
{}  花括号
[]  方括号
()  小括号
#   井字号
+   加号
-   减号
.   英文句点
!   感叹号

如果想要显示反引号，则可以使用 5 个反引号，注意最中间反引号与两边之间的空格：

1`` ` ``

2.11.4 Typora 主题

Typora 主题推荐使用的 Vue 或 Pie 主题，也可以在 Themes Gallery 选择喜欢的主题。

设置字体高亮

Markdown 语法高级设置：使用 == 包围字体，实现字体红色加粗。

步骤：

  1. 进入对应主题的 CSS 文件，修改定义高亮部分代码为：
12345678910/* heighlight. */
#write mark {
    //background-color: #EBFFEB;
    background:#FFFFFF;
    border-radius: 2px;
    padding: 2px 4px;
    margin: 0 2px;
    color: #FF0000;
    font-weight: bold;
}
  1. 打开 Typora，文件 > Markdown > Markdown 拓展语法 > 打开高亮。

还可以增加多个高亮显示：

  1. 不修改第一步中的文件，而是在 CSS 文件末位添加代码：
123mark{
    ...
}
  1. 添加快捷键：比如将新添加的高亮快捷键设置为 Ctrl + q
    • 打开 文件 > 偏好设置 > 高级设置 > conf.user.json
    • 加入代码：“Highlight”: “Ctrl + q” 在 “keyBinding”: 后面的大括号里面

设置图片边框

进入对应主题的 CSS 文件，在文件内添加：

123456/* img style */

    border: 5px solid #ddd;
